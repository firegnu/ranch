# paddock 需求：设置里用连线图看和改派活分工

2026-10-20，ranch/main 写，交用户转给 paddock。数据和改表都经 ranch 的命令；读表命令现装版本（`versions/7d2ac96`）已有，改表命令、格子说明、可选项、防冲突由 ranch R35 补，字段以那时 ranch `docs/CONTRACT.md`「`ranch dispatch cell` / `table`」一节为准。

## 用户原话

- 10-20：「我有一个想法，想在paddock中settings有一个专门的面板可以使用那种连线的方式去展示这个关系，而且可以定制修改。修改后关联的表格也就修改了（我觉得甚至都不用重新读取skill，因为表格的修改是实时读取的）」
- 10-20：「你的任务你做，paddock的任务padck做」

## 背景

主控派活时调 `ranch dispatch cell <格子>` 现查分工表：每个格子（如「其余：照方案实现、修 bug」）连到交给哪家、什么模型、什么强度，有的格子还连到交叉审查格子、返工后换到的格子。表由 ranch 内置，用户本机可以改某一格，改了下一次派活就生效，不用重装技能。

## 要的结果

1. Settings 里一个面板，用连线图展示这张表：格子（带说明）连到交给的家和模型、强度；交叉审查、返工换格子用另一种线。看得出每格来自内置还是本机改过。
2. 能在面板上改一格：交给哪家、模型、强度、审查格子、返工格子，强度和模型给下拉（选项来自 ranch）；能把一格恢复默认。改完就写进去，面板随之更新。
3. ranch 拒绝的改动（不合格、文件在别处被改过）要显示原因；文件被别处改过时提示刷新，不覆盖。
4. 各家的启动命令只显示，不能改。

## 规矩

- 只调 PATH 上的 `ranch dispatch` 命令、读 JSON；不读写 `~/.ranch` 里的文件。
- 格子有哪些、叫什么由数据决定，界面不写死。ranch 以后（R34）会把格子整个换成「档位 × 界面或非界面」，面板要照样能用。
- 什么活落进哪一格是 corral-dispatch 技能里的规则，面板不管，也不改技能。
- 新界面，先给用户看样子再做。
