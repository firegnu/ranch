## 环境与方法

- 使用 PATH 上的 `/Users/firegnu/.local/bin/corral`，链接目标为 `versions/5264a9d/bin/corral`；版本输出为 `{"contract":"1","ok":true,"version":"0.1.0"}`。
- 仅使用五个 `ranch/test-r42-<家>` 名字，Claude Code 因状态残留和不同测试模式按实例先停再重开，均带 `--label role=test --env CAIRN_DISABLE=1`，cwd 为本 worktree 的 scratch。开始前查询没有同名前缀的测试 agent；没有操作用户已有 agent。
- 启动命令末尾分别为 `-- codex --disable memories`、`-- pi`、`-- omp`、`-- amp`、`-- claude`，Claude Code 续测显式带 --permission-mode default 或 --permission-mode plan；没有加免确认参数。amp 空闲后用 send 送第一句，其他用 start 的 --prompt。
- 统一要求只在前台运行 sleep 30，不读写文件、不联网、不启动其他 agent；Claude Code 首轮先要求 Bash ls。Claude Code 续测按主控要求改用本机回环 ping，不访问外网。主测试者自己的 shell 命令均等前台结束。
- 每家及每个重开前的实例测完立即 corral stop，停止均返回 ok:true。没有登录、目录信任对话框，也没有批准“永远允许”。
- 下文状态 JSON 为原输出选字段，数值不改；屏幕摘录保留 read 原有的重复、残缺。“约 1 秒”是 keys 返回后等待 1 秒取样，不是精确的界面响应延迟。
- 部分样本 attached 是 1，但 last_human_input 一直为 null；没有通过 attach 输入。没有测 Slack 发送效果，末表提醒结论只指可提供给提醒的屏幕文本。
