### 1. 必须改：符号链接让规则目录和仓库补充文件的写保护失效

- **位置**：`crates/fence/src/rules.rs:343`、`:382`（路径只作字面规整，强制 deny_write 只加入原路径）；相关承诺见 `docs/CONTRACT.md`「整个 FENCE_HOME 及工作区 .fence.toml 始终禁止写」。
- **问题**：`.fence.toml` 可以是指向工作区另一文件的符号链接，`FENCE_HOME` 也可以指向一个已放行写的目录。fence 会正常读取这些规则，但生成的 denyWrite 没有保护实际目标。固定的 srt 0.0.80 对这种跨路径树的链接保留原拼写，不能替 fence 补上目标的禁止写。墙内因此能改下一次启动会读取的规则；这不是日志遗漏，是实际写保护失效。
- **复现**：在隔离 HOME 的工作区中创建 `repo-policy`（内容 `domains = []`），令 `.fence.toml -> repo-policy`；再令 `$HOME/.fence -> <工作区>/policy-home`。使用本次 fence、原版 runner 和真实 srt 运行合成 `/bin/sh`。写 `policy-home/local.toml` 返回 **0**，写 `repo-policy` 返回 **0**，写 `.fence.toml` 返回 **0**；外部读取确认规则文件已变成 `bad`。经 `$FENCE_HOME/local.toml` 写入及删除 `.fence.toml` 则返回 1，说明原路径被保护，但目标仍可修改。另测 HOME 本身为符号链接时，读真实路径下的假密钥仍被拒绝，不把该情形列为漏洞。
- **改法**：至少为强制保护的 `.fence.toml`、FENCE_HOME 同时保护原路径和解析后的实际目标；处理路径中间组件的链接和尚不存在的末级路径，保留原路径的防替换保护。无法可靠解析时明确拒绝启动，也可以先明确拒绝这些受保护路径使用符号链接。检查数据里的其他 deny_write 是否存在同样问题，并保留上述真实 srt 回归。不能仅依赖当前 srt 自动解析。

### 2. 必须改：Linux 文件拒绝事件没有按公开格式归一化

- **位置**：`crates/fence/resources/runner.mjs:35`–`:41`；对照 `docs/CONTRACT.md` 的 `denials.type/target` 和 `monitors.files` 语义。
- **问题**：runner 只识别含 `file-read` / `file-write` 的 macOS 文件日志。锁定的 srt 0.0.80 在 `dist/sandbox/linux-violation-monitor.js:76`–`:80` 生成的却是 `deny ${syscall} ${observedPath}`，例如 `deny openat /synthetic/protected`。这些已收到的文件写事件全部落到 `type:"other", target:null`，也不会把 `monitors.files` 置 true。这与公开的文件事件分类及「收到文件事件后确认能记录」的语义不一致，前端无法按约定判断 Linux 文件监视是否已工作。
- **复现**：审查 worktree 外复制 runner，唯一改动是在真实 srt violation store 中注入一条上游格式的合成事件 `deny openat /synthetic/protected`。运行 `/bin/sh -c 'exit 0'` 后得到 `{"type":"other","target":null,"detail":"deny openat /synthetic/protected"}`，`monitor.json` 为 `files:false`。这是事件解析的合成验证，没有声称跑过 Linux sandbox。
- **改法**：按锁定版本 Linux monitor 实际产出的 syscall 格式识别写事件，输出 `file-write` 和路径，并据此确认 `files:true`；继续保留它只是写尝试诊断、路径可能不准的说明。增加两平台事件格式的合成回归，不需要等 R17c 的整机实测才能验证解析。

### 3. 建议改：check 提前拒绝 srt 不接受的域名格式

- **位置**：`crates/fence/src/rules.rs:325`–`:355`、`crates/fence/src/main.rs:34`–`:40`；实际 schema 校验直到 `resources/runner.mjs:27` 才发生。
