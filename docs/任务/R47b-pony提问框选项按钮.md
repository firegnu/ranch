## 要做的

1. Claude Code 提问框的 Needs you 提醒，有 `status.questions` 且没被截断时，每道题带按钮：单选题一排选项按钮；多选题勾选框加「提交」。用户 10-23 看过的样子见上；Slack 的块和字数限制让样子要变的，照最接近的做，写进完成记录。
2. 选过的题在消息上显示选了什么，可以改选，直到全部题目都答完。全部答完时，pony 把答案按题号、题目短名（`header`）、选项名拼成一段话，走 R45 提问框回答现成的路（核对、按一次 Esc、等空下来、加前缀送）。
3. 打字回答照旧可以：在线程里打字，和现在一样当作回答送出。按钮答到一半又打了字，以哪个为准你定，写进完成记录；不能两份都送。
4. 题目被截断、不是 Claude Code 的提问框、或者平台没有按钮：照旧只发文字提醒，不给选项按钮。
5. 答完把按钮去掉，消息上写 `已答：1. 米饭 2. 茶 3. 鸡腿、凉菜（10:42）` 这类说明。框已经在电脑上答掉、换了框、人刚操作过：不按、按钮去掉、说明原因，照 R47a 的规矩。
6. 文档：DESIGN §10、R38a、pony README 里提问框那几句加上按钮。对 paddock 的影响写进完成记录。
