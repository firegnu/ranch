## 要做的

1. 本机 `git push <host>:~/Develop/ranch main`，那边切到 main，删掉留着的 `r10-linux` 分支。
2. 那边跑 `cargo test --all-targets`、`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check`。有不过的停下来告诉用户；要改代码的另开一件，在本机派出去修。
3. 那边 `cargo run -p ranch-package` 打包，核对 `BUILD.txt` 的目标是 Linux、工作区干净。
4. 部署（用户 10-17 让主控经 ssh 敲）：两个链接切到新版本目录，跑 `corral install-skills`、`ranch dispatch install-skills`。没有在跑的 agent，不跑 `corral upgrade --all`。
5. 实测：从本机经非交互 ssh、用 corral 绝对路径调，pi、omp 各开一个 `ranch/test-*`（`--label role=test`，`--cwd` 用临时目录）：状态 idle → working → idle，`send` 回 confirmed，`reply` 拿到原文，看 pen 没有多余的描述符，用完 stop。
6. 更新 HANDOFF 里远端装的版本，补收尾提交。
