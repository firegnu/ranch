### R1 — 必须改：遍历过程中退出的中间进程会让新孙进程漏冻

- **位置**：`crates/corral/src/freeze.rs:7–26,44–55`；`crates/corral/src/pen.rs:390–394`。
- **问题**：先完整执行 `descendants(agent)`、再逐个 STOP，遍历期间另开会话的子进程仍可 fork 和退出。具体顺序是：A 已 STOP；查询 A 得到子进程 B；B fork 出 C 后退出；再查询 B 时 C 已重挂到 PID 1，查不到；下一轮仍只从 A 开始，因而永远找不到 C。对 B 的 STOP 失败也被忽略，最后仍返回 `paused:true`。这不是“暂停之前就已脱离”的进程，而是冻结过程中刚产生的孙进程，仍可继续运行和联网，未达到第 1 条及“不漏冻”的验收。
